# 🔍 Deep BiLSTM OCR Text & License Plate Extractor

A deep learning Optical Character Recognition (OCR) web application built with **Python**, **EasyOCR (CRNN + BiLSTM)**, **OpenCV**, and **Gradio**.

## Features
- **Full Document & Multi-Page PDF Extraction** (250 DPI rendering)
- **Road Vehicle Number Plate & Faint Text Detection** (CLAHE contrast enhancement + 2x upscaling + dual-pass fusion)
- **Live Mobile Front/Back Camera & Webcam Support**
